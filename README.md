# 梦想家

和角色一起住的小家。按角色人设盖一个你们共同的家，他会回家、和你互动、回你的小纸条。每个角色都有自己的家，互不影响。

安装：酒馆「扩展」→「安装扩展」，填 `https://github.com/Zaiyebuzuoyouqingdetiangou/mengxiangjia`。
进入：魔法棒菜单里的「梦想家」；扩展设置里也有「打开梦想家」按钮。

## 0.1.0 第一版：盖房子、他回家、小纸条

- 盖房子：读取角色卡、你的用户人设和角色世界书，由 AI 设计这个家——名字、来历、配色、几个房间、每个房间放什么家具。可以选房子大小（一间小屋、小公寓、带院子），写补充要求，勾选「留些空位，等我们一起布置」。不满意可以换一版，满意了点「就住这里」。
- 小屋首页：画出房间正面图，家具按设计摆好，夜里会暗下来、落地灯会亮；几个房间之间可以切换。他在家时，头像会出现在他待着的那件家具旁边。
- 他回家：打开小屋时，离上次回家够久他就会回来（间隔在设置里调，也可以改成只在你点「等他回家」时回来）。回家会写一个小场景，给你两三件可以做的小事，也可以自己写一句，他会接着回应。
- 点家具：房间里的每件家具都能点，可以叫他过来、在旁边陪他，或者在那儿做点别的。
- 小纸条：分道歉、纪念、日常、想你、谢谢、生气了，可以贴在门边、冰箱、枕边或书桌。可以让他马上回，也可以等他回家时再读；他回家时偶尔也会自己留一张。有新纸条时，房间里和入口上会提示。
- 回家记录：每次回家的场景和你们的来回都留着。
- 生成可以跟随当前 API，也可以用副 API（选酒馆里的连接配置，或手动填写接口）；副 API 走酒馆后端转发，出错时直接告诉你，不会悄悄换成主 API。
- 家存在酒馆的扩展设置里，换设备也在。纸条最多留最近 300 张，回家记录留最近 40 次。
